# PANISA task homepage

Public GitHub Pages front door for a private report. Preserve the existing report URLs and permissions. Do not copy report snapshots or customer data into this repository. Do not upload raw data, tokens, private audit paths or customer identifiers.

Use tasks.json as the source of task status. Read README.md's status contract before updates. Never infer a completed run from its schedule, a page visit or successful publication of this website. Customer-list use for advertising requires verified rights; data originally supplied through Shopee is excluded until those rights are confirmed. Do not treat chat-order phones as automatically authorized either.

Check status logic, rendered desktop/mobile layout, filtering, report links and failed-fetch behavior when relevant. Publish through GitHub Pages; the linked report remains on its original service.
